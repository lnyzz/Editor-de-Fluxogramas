# Editor de Fluxogramas

Editor visual de fluxogramas desenvolvido em **HTML, CSS e JavaScript**, utilizando **SVG** para a representação dos elementos.

O projeto permite criar, editar, organizar, salvar e exportar fluxogramas de forma simples e visual, sendo especialmente voltado para os exercícios das aulas de **Lógica de Programação do professor Tavares**.

## ✨ Funcionalidades

* Criação e edição visual de fluxogramas
* Conexões entre os elementos
* Edição dos textos dos elementos
* Movimentação dos elementos
* Salvamento automático do projeto
* Importação e exportação de projetos em **JSON**
* Exportação dos fluxogramas para **SVG e PNG**

## 📚 Exercícios resolvidos

Os exercícios desenvolvidos durante as aulas estão disponíveis na pasta **`Exercícios`**.

Para visualizar um exercício:

1. Baixe o arquivo `.json` correspondente.
2. Abra o [Editor de Fluxogramas](./index.html).
3. Utilize a opção **Abrir**.
4. Selecione o arquivo `.json` do exercício.

Dessa forma, o fluxograma será carregado diretamente no editor.

## 🤖 Auxílio de IA

Os fluxogramas criados pelo editor podem ser salvos em formato **JSON**. Isso permite utilizar um fluxograma já pronto como exemplo para ensinar uma IA a seguir o mesmo padrão de estrutura.

Por exemplo, é possível fornecer à IA:

> "Este é o JSON de um exercício já resolvido. Entenda o padrão utilizado e gere o JSON para o exercício a seguir..."

Em seguida, basta informar o novo exercício.

A IA pode então gerar um novo arquivo JSON seguindo a estrutura utilizada pelo editor, que poderá ser importado diretamente para visualizar e editar o fluxograma.

> **Dica:** quanto mais exemplos de exercícios forem fornecidos à IA, maior será a facilidade para ela identificar o padrão utilizado.

## 🚀 Como executar

O projeto não necessita de instalação de dependências.

Basta clonar o repositório:

```bash
git clone https://github.com/SEU-USUARIO/Editor-de-Fluxogramas.git
```

Depois, abra o arquivo `index.html` no navegador.

## 🎯 Objetivo

O objetivo do projeto é facilitar a **criação, organização e visualização de fluxogramas**, tornando mais prática a resolução dos exercícios de lógica de programação.
