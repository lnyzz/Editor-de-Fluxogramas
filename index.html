Como usar
Clique em uma função para adicionar ao canvas. Clique em um bloco para editar o texto. Arraste o bloco para mover. Em uma área vazia, arraste o botão esquerdo para navegar. Para conectar, selecione um bloco e arraste a bolinha azul até outro bloco. No condicional, use as bolinhas da esquerda e da direita para os dois caminhos. A saída da direita representa verdadeiro e a esquerda representa falso. Use o conector circular para unir os caminhos novamente. Clique em uma linha para selecioná-la e pressione Delete para removê-la.
