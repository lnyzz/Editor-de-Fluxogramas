Como usar
Clique em uma função para adicionar ao canvas. Clique em um bloco para editar o texto. Arraste o bloco para mover. Em uma área vazia, arraste o botão esquerdo para navegar. Para conectar, selecione um bloco e arraste a bolinha azul até outro bloco. Clique em uma linha para selecioná-la e pressione Delete para removê-la.
